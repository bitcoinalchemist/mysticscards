# Mystics Cards

Explore the symbolism of playing cards through birthdays, Life Scripts,
personal cycles, and relationships. Mystics Cards brings these readings together
with interactive Quadrations charts in a single browser-based experience.

**[Explore mysticscards.space](https://mysticscards.space/)**

## Explore the cards

- **Birthday cards** — find a card from a birthday, or select a card directly
  to explore its meaning and associated dates.
- **Life Scripts** — explore the seven planetary cards connected to a birth card.
- **Personal cycles** — follow the site's card-based cycle readings.
- **Relationships** — add a second person to explore a combined card and
  connections between the two cards.
- **Quadrations** — browse Earthly, Spiritual, and annual spreads, with solar
  values, displacements, and binary views.
- **Optional birth details** — explore planetary ruling cards, a Chinese year
  profile, and solar-time tools when the relevant details are available.

Cardology is presented as a symbolic practice for reflection and exploration,
rather than a scientifically established prediction system.

## Contacts and privacy

Save birthdays as contacts, organise them with tags, and export or import them
to keep a backup or move between browsers.

Calculations run in your browser. Saved contacts and preferences stay in that
browser's local storage, with no built-in cloud account or automatic sync.
Clearing site data can erase them, so export contacts you want to keep.

For details about browser storage, hosting, and use of the readings, see the
[privacy and use notes](LEGAL.md).

## About this repository

The site is hand-authored HTML, CSS, and JavaScript, with no framework or build
step. The main page is a standalone file containing its styles, classic scripts,
fonts, card artwork, and reference data. A web manifest and service worker support
installation and offline use in compatible browsers.

| File | Purpose |
| --- | --- |
| `index.html` | Complete site and embedded resources |
| `sw.js` | Offline caching and cache updates |
| `manifest.webmanifest` | App installation details |
| `assets/` | Installation icons and social preview image |
| `AGENTS.md` | Project guidance and maintenance conventions |
